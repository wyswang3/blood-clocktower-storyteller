需求与实现

普通用户在安卓平板安装一个 APK 后，点图标直接打开房主大厅；填写 DeepSeek API Key 后自动验证并保存，不需要 Termux、命令、模型下载或另外安装隧道工具。服务器仍运行在平板，手机浏览器加入。

新增原生启动界面、独立后台服务、内置 Node.js 和安卓编译的 cloudflared、原生分享、同网/公网模式、切网更新、失效链接撤回和自动重试。游戏规则、每日提名限制、禁止自提、僧侣可连续守同一人及 AI 权限保持原约定。

存储核算

开发工作区清理前约 1 GB：约 859 MiB 为构建、下载和验证产物，约 152 MiB 为原始图片；实际网页与图片约 5.29 MiB。通用 APK 内含三种架构的原生运行库，安装到 ARM64 后预计基础占用约 180–200 MB；这是按 APK 与对应解压库计算的估算，尚未在用户平板系统存储页测量。建议安装时预留 500 MB。模型在 DeepSeek 云端，不下载到平板。

本次清理只针对可重新下载或重新生成的构建重复文件，保留原图、源码、历史备份、签名、最终发布包和验证证据。手机使用浏览器，不安装 APK。

实际清理结果（不含 .git）：从 1,113.81 MiB 降至 471.72 MiB，移除 7 项重复构建/下载产物共 642.09 MiB；223 个受保护文件清理前后哈希一致。记录保存在 artifacts/apk-storage-cleanup.json，目录大小后续会随日志和打包小幅变化。

已知恢复边界

同一网址下断线可恢复座位，平板重启可以读回对局。公网域名、IP 或端口改变后的手机座位迁移未实现，已列为 M07；正式对局中避免重启或切换平板网络，聚会前先测试。

隐私与更新

应用管理令牌不进入网页、公开日志或游戏存档；原生控制接口同时验证本机地址、Host 和随机令牌。公网不能通过伪造 HTTPS 代理头获取管理信息。房主页面沿用受限密钥配置流程，只有私密服务端保存 API Key。

APK 只包含白名单游戏源码和公开依赖，不带密钥、真实存档、签名私钥、登录凭据或其他工作区项目。对局存档继续使用 v2；APK 与旧 Termux 数据不自动迁移。后续相同签名覆盖安装保留应用数据，卸载或清数据会删除。

后续维护

签名、应用 ID、versionCode、数据位置、运行库来源和后续待办见 技术手册。安卓模拟器通过只证明该测试环境可运行，不能代替 ARM 平板、16 KB 页设备、厂家后台策略和现场网络验收。
