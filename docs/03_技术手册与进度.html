1. 产品目标与当前范围

目标：几个朋友线下玩《血染钟楼》，无人需要专职退出当说书人。安卓平板同时运行服务器和公共屏，每人一部手机。朋友可各用流量或 Wi-Fi，加入同一个公网房间；也保留共同局域网方案。

最终说书人应能在合法范围内主动安排信息、观察局势、照顾新手、引导讨论、营造气氛和解释复盘。后续主模型计划使用 DeepSeek。维持可解释性和推理空间，不能靠改写已发生事实强行平衡胜负。

当前实现暗流涌动 22 角色、5–15 人、单进程单房间。0.3.0 完成当前范围的规则核对与修复，详情见 逐角色核对。0.4.1 新增平板填写密钥后自动连接、保存和热加载；0.2.0 起已有夜间信息候选选择；0.5.0 新增原生安卓 APK、内置 Node/cloudflared、独立后台服务、图形联网与重试；完整 AI 主持、账号系统、游戏内聊天和语音尚未实现。

4. 架构与数据流

手机 / 平板浏览器
  → HTTP 页面与 WebSocket 消息
  → server.js：座位认证、房主权限、广播、持久化
  → Game：唯一对局状态源
   → setup / night / day：发牌、夜间与白天结算
   → state：公共、座位、说书人三类视图
   → ai-storyteller：监听待裁量请求
       → 引擎生成候选 → DeepSeek 选择候选编号
       → 校验编号和请求仍有效 → 发给对应手机

跨网络路径：浏览器 → 临时公网 HTTPS 地址 → cloudflared → 平板本机 HTTP 服务。隧道只提供可达性，不替代座位认证。平板本机访问地址与手机分享地址分开；公网地址不是房间存档的一部分。

服务端使用 Node 18+ 内置模块，无第三方运行依赖。APK 使用 Node.js Mobile 18.20.4；备用 Termux 使用官方 nodejs-lts 包。端到端测试使用内置 WebSocket，建议 Node 22+，本轮为 Node 24.20.0；最低运行版本不等于测试工具最低版本。

6. DeepSeek 配置和协议

普通用户见 连接 DeepSeek，直接用大厅按钮。没有图形设置标志时环境变量优先：DEEPSEEK_API_KEY、DEEPSEEK_BASE_URL、DEEPSEEK_MODEL、AI_TIMEOUT_MS、AI_ENABLED。默认关闭，密钥有效配置后才允许从平板启用。默认模型 deepseek-flash，以本次查询官方文档为依据，不应永久硬编码模型可用性假设。

请求：POST {baseUrl}/chat/completions，Bearer 认证、非流式、非思考模式、JSON 输出，最多 512 输出 token。普通端点要求 HTTPS；仅允许本机 HTTP 作为测试替身。

模型输出：{"optionId":"option-0","reason":"私密的简短裁量依据"}。只使用通过验证的编号，实际卡片取自服务器候选；多余的模型卡片和身份字段不会被采用。无裁量空间时不调用服务商。

房主 WebSocket 消息：{t:'host', action:'setAI', enabled:true|false}；单次连通测试为 {t:'host', action:'testAI'}。均受房主 PIN 会话权限保护。测试发送空对局上下文，返回 ai-test 消息；不修改游戏。

public.ai 仅公开 configured / enabled / state。room.aiDecisions 保留最近 100 条私密记录。API Key 仅用于认证头，不进入模型消息正文；座位 token、房主 PIN 不发送给模型。魔典进入私密裁量请求，不得复用于未来公开主持。

候选由信息生成器采样去重，加入健康隐士/间谍每次互动可变化的登记；默认自动模式仍用固定合法策略，不穷举所有组合。镇长转移、传位和日间登记由引擎自动选，模型无权直接执行特殊效果。旧可信外部 st-info 协议允许自由卡片，与受约束的 DeepSeek 适配器是不同入口。

7. 必须守住的约束

  • 酒鬼真实角色仍是外来者，显示角色只能是本局未在场的镇民。模型没有改身份的权限。
  • 清醒健康能力的结果不能自由造假；醉毒可给真或假信息，真实能力效果仍按规则执行。
  • 自动结算不按善恶票数直接结束三人局。提前宣布使用已授权的房主入口。
  • 提名“每轮”在本项目指每个白天，每人一次提名、一次被提名；禁止自提是用户确认的本桌约定。
  • 幽灵票仅同意消耗，反对和未投不消耗；本轮资格分母不能随投票缩小。
  • 一条请求只执行一次；超时、跳过、模式切换、暂停、重开后迟到结果不得覆盖当前请求。
  • 身份、醉毒、魔典、AI 理由不得进入公共屏；用户数据、模型输出和玩家名称都按数据处理。
  • 禁止根据旧设计稿直接实现白天改酒鬼、任意改红鲱鱼或改写既有事实。

10. 更新、打包与回滚

  1. 先读根目录 AGENTS.md、本文和最近验证记录，检查当前文件；没有 Git 仓库时先做精确文件备份。
  2. 修改前重现问题，新增能区分错误与正确行为的测试。避免只检验实现本身。
  3. 运行受影响测试及必要的整局、隔离和联机验证；记录权限限制与未测平台。
  4. 同步三份说明的功能状态、版本和操作文案，运行 node tools/build-docs.js。
  5. Windows PowerShell 7.2+ 中运行 ./tools/package-android.ps1；检查清单与 SHA-256。按白名单收录运行文件、说明和空密钥模板。加 -IncludeTests -OutputName blood-clocktower-source-v0.5.0.zip 生成源码包。私密仓库源码与发布附件分别交付，不把备份和测试日志提交。
  6. 严禁把 ai.local.json、room.json、日志、原图备份和测试房间打进普通用户包。技术人员从源码工作区维护测试，用户包不含完整测试源码。
  7. 更新用户设备前停止旧服务，备份旧目录与私密配置/存档。先验小测试，再验全员局；出现兼容问题时停止服务后恢复旧目录。

新增存档字段须给旧存档默认值；改变语义时增加格式版本和迁移说明，不能静默重发身份或恢复已结束旧局。升级密钥配置要保留用户自己的文件，不能用模板覆盖。

11. 已知维护风险

手写 WebSocket、单文件 JSON 落盘和单房间设计适合当前小规模场景，但不等于生产级多人平台。公网链接可被持有者打开，PIN 主要防误操作。当前目标是朋友局可用、易运行和可维护，不扩大到多租户或商业账号体系。

当前角色机制已逐项核对，但可选登记和裁量组合并非穷举。早期浏览器代理报告不能替代安卓实测。新角色、旅行者、传奇、其他剧本都不在本轮范围；不能把本轮测试扩大解释成已支持这些内容。

12. 0.3.0 数据与规则变更

夜序按当前官方公开通用表筛选本剧本，间谍移至夜末，掘墓人在共情者/占卜师之后；旧实体表位置见核对说明。夜间死亡对引擎立即生效，对普通视图到黎明才公布。

存档 v:2 新增 demonBluffs 与 infoReminders，旧存档默认空列表/对象，不追补三张牌或重发身份。day.executed.died 区分处决与因处决死亡；旧记录缺省按原先实际死亡语义读取。每轮提名结果保存 threshold，避免白天死亡后倒改旧门槛。

slayerShots 仅记录宣称，真实次数由 slayerUsed 判定；允许投票中行动和重复假宣称，结束白天后拒绝。管家票不作废，不再生成 butlerVoided；私密提醒不以醉毒决定是否出现。旧局曾发出的信息无法撤回，建议结束旧局后更新、另开新局。

13. 0.4.1 图形配置与维护约束

  • 大厅及设置中的“连接 DeepSeek”打开密码框，只接收 API Key；无端点/模型选择，默认使用官方地址和 deepseek-flash。模型在云端，无需下载。
  • 房主 WebSocket：{t:"host", action:"configureAI", apiKey:"..."}。仅已认证房主、平板本机连接或可信本机 HTTPS 反向代理可调用；普通玩家、说书人及明文远程局域网连接被拒绝。
  • 先以空对局上下文测试一次，再原子写入私密配置，最后替换客户端并启用。任一步失败保留旧连接/旧配置，重复点击共用忙状态，不并发收费测试。
  • managedByUI:true 的密钥与 enabled 优先于旧环境值；没有这个标志时维持原环境优先。端点和模型可由维护者的环境变量覆盖，网页不能指定。AI_CONFIG_FILE 允许隔离私密配置位置。
  • ai-setup 是仅房主收到的工作/成功/错误消息，带 allowed 标志，无密钥。重连重新发送当前状态。ai-settings 仅在开关已应用且保存完成后确认；避免把更早的公开状态误当成写盘成功。
  • 密钥不放 URL、浏览器存储、公共状态或 room.json。私密临时文件使用随机名、0600、排他创建及原子替换，失败清理；忽略 ai.local.json*。
  • 暂停优先立即停止调用。即便写盘失败也保持本次暂停，并明确提示下次启动需确认；启用写盘失败则恢复原开关。替换连接会取消旧请求并按引擎回退。
  • 僧侣保留官方连续守护规则，不加入本桌新限制；有跨夜与存档恢复回归。

14. 0.5.0 原生安卓封装

架构和生命周期

MainActivity 是原生启动器和受限 WebView；RoomService 在独立的 :room 进程启动内置 Node.js，游戏引擎与手机协议共用原有实现。应用打开后直接进入已认证的本机房主页面，不需要终端或手输 PIN。平板仍是唯一房间服务器。

Node.js Mobile 不支持同一进程中停止后再启动 V8，因此停止时先通过私密接口落盘、结束隧道，再结束独立服务进程。重启按钮重建该进程，主界面重新绑定。前台服务有持续通知和 CPU 唤醒锁，平板显示时保持屏幕点亮；后台存活仍受厂家省电策略影响，必须真机验收。

数据与权限

  • 应用 ID 固定为 com.wyswang.clocktower，最低 Android 8.0，目标 API 35，包含 arm64-v8a、armeabi-v7a、x86_64。升级需递增 versionCode 并保留签名。
  • 游戏资源复制到应用私有的 files/game-{version}，配置与存档独立放在 files/ai.local.json、files/room.json。覆盖安装保留；卸载或清除数据删除。关闭自动系统备份，不从共享下载目录执行代码。
  • WebView 只在内部打开本机端口；禁用 file/content 访问，不安装 JavaScript 原生桥。外部网页交给浏览器。DeepSeek 密钥仍只经过原房主配置流程。
  • Java 与服务之间使用非导出 Binder；每次服务启动生成 32 字节随机管理令牌。/__native/* 同时要求本机源地址、准确的 127.0.0.1 Host 和管理头。令牌不进网页、游戏存档、控制台和加入链接。公开接口不返回房主 PIN。
  • 管理接口：GET /__native/status；POST 的 /retry、/mode/internet、/mode/lan、/network/{IPv4或none}、/stop 均位于 /__native 下。状态仅 Java 层使用；停止先保存再响应。

联网

APK 内置从 Cloudflare 官方 2026.10.3 源码用 Android NDK / Go 编译的 cloudflared。使用 HTTP/2 临时隧道，默认尝试公网连接，不需要 Cloudflare 账号或域名。URL 与注册成功同时出现才公布链接；失败/退出清除链接，10 秒后重试，切网和手动重试取消旧进程。切到同网模式立即停止隧道。

原生系统 API 提供局域网 IP，解决部分安卓禁止 Node 枚举网卡的问题。公网和同网链接不能混淆；同网模式不能承诺所有手机热点允许设备互访。现场公网不可达时按主人指南切换，不把密钥错误当成隧道故障。

构建与签名

私密仓库 .github/workflows/android.yml 使用 JDK 21、Gradle 8.9、AGP 8.7.3、SDK 35、NDK 27.2、CMake 3.22.1 构建和 lint，并安排 Android 模拟器验收。Node.js Mobile 18.20.4 官方压缩包固定 SHA-256；cloudflared 使用官方固定标签、go.sum 校验依赖。源码包不含已下载运行库和编译缓存。

构建物下载后，维护者运行 tools/sign-android.ps1 在本机签名并核验。私钥与 DPAPI 加密密码位于忽略的 artifacts/android-signing/，不上传仓库、构建服务或发布附件。密码解密依赖当前 Windows 用户；迁移维护机器前应由当前用户安全导出并备份签名材料。签名丢失会影响覆盖更新，不能随意生成新签名替换。

本版沿用 Node.js Mobile 官方现成运行库；上游版本较旧。必须持续关注运行库更新与 16 KB 页设备兼容性，不能把三种 ABI 已打包等同于所有安卓机型通过。用户具体平板、真实 DeepSeek、移动运营商及长时间后台测试仍列为待验。

旧 Termux 数据不会自动导入。确需迁移时，先停止两边的服务，通过受控本地方式把原 room.json 与 ai.local.json 放入应用私有目录；当前没有面向普通用户的导入按钮，不应让用户在群里传存档或密钥。建议结束旧局后用 APK 另开新局并重新填写密钥。

存储空间与维护清理

本轮清理前工作区约 1 GB，其中构建下载、解包和测试产物约 859 MiB，用户原始图片约 152 MiB；实际 public/ 资源约 5.29 MiB。原图、源码、历史备份和签名应保留，普通用户不需要复制整个开发工作区。

通用 APK 约 91 MB，体积主要来自三种 ABI 的 Node.js、cloudflared 和 C++ 运行库。系统仅为本机提取对应 ABI；常见 arm64 设备基础安装占用预计约 180–200 MB，属估算，待真机系统存储页核实。安装时建议预留 500 MB；DeepSeek 云端模型不下载。手机只缓存网页资源。

本机可清理已核验发布后的重复构建 ZIP、解包目录、旧未签名 APK 和依赖下载压缩包。必须先核对绝对路径位于 artifacts/，保留 android-signing/、最终签名 APK、源码包、验证证据以及用户配置和存档。不要把“清理缓存”写成删除整个 artifacts/。CI 附件保留 14 天；正式发布附件单独保留。后续可按平板 ABI 分发以减少下载，但本版优先提供一个通用安装包，避免让非技术用户选择架构。

版本化游戏资源会保存在 files/game-{version}；每次升级可能留下约 5 MB 的旧资源。自动回收旧版本目录尚未实现，禁止为省空间引导用户清除应用数据。
