说明首页血染钟楼 · v0.5.0

平板主人的安装与测试指南

适用版本：0.5.0｜更新日期：2026-10-23｜设备：安卓 8.0 及以上平板。

平板运行房间服务并显示公共局面，每人用自己的手机看身份和投票。平板主人也能参加游戏，日常操作不会显示其他人的身份。

一、下载和安装

  1. 下载本次交付的 blood-clocktower-v0.5.0.apk，保存到平板。也可登录有权限的 GitHub 账号，在 最新版本 的附件中下载。
  2. 在“文件管理 / 下载”中点这个 APK。若系统询问，允许这次使用的文件管理器“安装未知应用”，然后点“安装”。不需要开启开发者模式或 USB 调试。
  3. 安装后点 “血染说书人” 图标。首次准备可能稍慢，等到大厅出现即可。若询问是否允许通知，建议允许，方便确认房间仍在运行。

不用安装 Termux，不用解压游戏源码，不用输入命令，也不用单独安装联网工具。 应用已包含游戏服务和公网连接组件，模型仍在 DeepSeek 云端。

需要安卓 8.0 及以上；安装包包含常见的 64 位和 32 位 ARM 平板版本，也包含用于电脑安卓模拟器的版本。你们的具体平板仍需按下面步骤实测。

安装包约 91 MB。常见 64 位 ARM 平板安装后的基础占用预计约 180–200 MB，安装时建议至少留出 500 MB 可用空间，供下载、解包和系统临时文件使用；实际以系统应用详情为准。DeepSeek 模型在云端，不会往平板下载几个 GB 的模型。手机只打开网页，不需要下载 APK 或源码 ZIP。

二、第一次开局：三步

  1. 连接 AI（可跳过）：大厅点“连接 DeepSeek”，粘贴 API Key，点“保存并连接”。等待提示已连接、已保存。不要填代码、网址或模型名。
  2. 邀请朋友：顶部出现“公网房间已连接”后，点“分享加入链接”，把链接发给这桌朋友。大家用手机浏览器打开、输入名字并选座位。
  3. 开始游戏：所有人到齐后，在平板点“开始游戏”，各自在手机确认身份，再由平板开始第一夜。

平板上网可以用普通 Wi-Fi，也可以连某个人的热点。公网连接成功后，其他人可以各用流量或不同 Wi-Fi。玩家手机不用安装 APK，也不用填写密钥。

AI 连接测试会产生一次很小的接口调用，按 DeepSeek 账户规则计费。不连接 AI 也能完整开局；夜间 AI 失败会自动回退。首次配好后，下次打开自动读取；暂停 AI 也会被记住。详见 DeepSeek 配置。

三、公网不通时怎么处理

  1. 先确认平板能正常打开普通网页；热点供网的手机也需要有流量。
  2. 点顶部“连接设置 → 重新连接公网”。连接变化后要分享新链接，朋友重新打开。应用也会自动重试。请在发牌前确认大家能加入。
  3. 仍然连不上时，改用“连接设置 → 大家连同一 Wi-Fi / 手机热点”，让所有手机和平板连接同一个网络，再分享链接。

公网房间使用临时连接服务，不需要账号或域名，但可达性取决于现场网络；仅填写 DeepSeek 密钥不能解决公网不可达。旧链接失效时应用会撤回。

对局中尽量保持平板网络和服务不变。 同一链接下的普通断线可以恢复座位；如果临时公网地址、局域网 IP 或端口改变，手机会将它视为新网站，本版还不能自动找回旧地址下的座位。平板存档仍保留，但可能需要另开一局，不能把“重新分享链接”理解为无损恢复所有手机。最好在聚会前完成不同网络测试。

同一 Wi-Fi / 热点模式下，关闭 AI 后可以不联网玩。游戏主要传文字，七台手机的游戏流量很小；若连不上，还应检查路由器设备隔离、热点人数上限或省电策略。

四、聚会前先测试

先用一部手机确认能加入，再让七人完整走一夜：

检查怎么操作通过标准
平板启动安装后点图标大厅正常出现，不需打开其他软件
手机加入打开刚分享的链接并选座平板显示名字，手机记住座位
不同网络公网模式下让一部手机关闭 Wi-Fi、使用流量仍能进入同一房间

切后台平板回桌面几分钟后再打开，手机也切后台再回来通知仍在，恢复原局和原座位

不要用一直点“跳过”来代替首夜测试。测试结束后点“重开一局”，正式局重新发牌。模拟器和自动测试不能替代你们的平板、运营商与真实账号验收。

五、平时需要记住的操作

  • 平板保持供电和联网。系统电池设置若有“不限制后台运行”，可对“血染说书人”开启；不要在游戏中清理后台。
  • 返回桌面会继续运行房间；通知栏点一下可回来。真正结束时点顶部“关闭房间 → 保存并关闭”。下次打开可恢复。
  • 顶部“连接设置”可切换公网/同网模式、重连或重启服务；不会重新发牌。网络恢复后链接可能改变，要重新分享。
  • 白天的“开始提名”“结束提名”、进入下一夜仍需要平板操作。
  • 全桌决定提前结束时，在游戏设置里选择“提前结束”、输入获胜方并再次确认；会亮牌。自动判定仍使用标准规则。

六、更新和常见问题

以后下载新版 APK，直接点开 覆盖安装。只要来自本项目的同一签名，安卓会保留应用里的密钥与存档。不要先卸载旧版，也不要点系统“清除数据”；这两种操作会删除本机数据。旧 Termux 目录不会被 APK 自动导入或删除，维护者需要迁移时按技术手册处理。

现象处理
安装被拦截允许当前文件管理器安装未知应用，确认文件下载完整
提示与已安装版本冲突请维护者检查版本和签名；不要直接卸载，避免丢失存档
大厅很久没出现等半分钟，再到“连接设置 → 重启应用服务”；仍失败请记录型号和安卓版本
公网一直连接中检查平板上网，重新连接公网，或全员改用同一 Wi-Fi / 热点
手机突然断线检查平板是否被清理后台或断网；若链接变化，重新分享，不要马上重开游戏
手机丢了座位使用原来的浏览器和链接；不要清浏览器数据。地址变化后的座位恢复尚未支持
AI 验证失败重新复制完整密钥，检查账户余额和平板网络
