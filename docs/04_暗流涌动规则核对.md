# 暗流涌动官方规则核对

版本：0.3.0｜核对日期：2026-10-22｜范围：22 个角色、5–15 人，无旅行者和传奇角色的标准暗流涌动。

本文对应当前代码、官方依据与测试。覆盖标准机制不等于穷举全部说书人策略；信息候选仍有限采样，日间登记与镇长转移等由引擎自动选择。完整 AI 主持及特殊效果裁量入口尚未实现。

## 一、依据与夜序版本

能力和互动依据 [官方角色索引](https://wiki.bloodontheclocktower.com/Trouble_Brewing)、各角色说明、[能力规则](https://wiki.bloodontheclocktower.com/Abilities)、[状态规则](https://wiki.bloodontheclocktower.com/States) 和 [规则解释](https://wiki.bloodontheclocktower.com/Rules_Explanation)。正文采用中文转述。

夜序采用 [TPI 官方公开 nightsheet.json](https://github.com/ThePandemoniumInstitute/botc-release/blob/main/resources/data/nightsheet.json)，筛选本剧本角色，已将核对后的列表保存于 `tests/fixtures/official-tb-night-order.json`，测试无须联网。通用表与旧实体表有版本差异，不能混称同一份流程表。本版使用公开通用表：间谍在夜末，掘墓人在共情者、占卜师之后；0.2.0 使用旧实体版位置。

首夜：爪牙信息 → 恶魔信息 → 投毒者 → 洗衣妇 → 图书管理员 → 调查员 → 厨师 → 共情者 → 占卜师 → 管家 → 间谍 → 黎明。

其他夜：投毒者 → 僧侣 → 红唇女郎角色变化提醒位 → 小恶魔 → 守鸦人 → 共情者 → 占卜师 → 掘墓人 → 管家 → 间谍 → 黎明。

红唇实际接管发生在真恶魔死亡时，提醒位不额外发动能力。新小恶魔当晚不再次击杀。5–6 人跳过首夜爪牙/恶魔信息，恶魔也不拿三个伪装提示；7 人以上才提供。参照 [官方词汇表的 Demon info / Minion info](https://wiki.bloodontheclocktower.com/Glossary) 与 [Toymaker 的正常开局信息说明](https://wiki.bloodontheclocktower.com/Toymaker)。

## 三、胜负与投票

- 真恶魔死亡后先处理合法接管/传位；仍无存活真恶魔则好人立即胜。仅剩两人且恶魔存活则邪恶立即胜，不继续发夜间信息。
- 圣徒健康且因处决死亡触发邪恶胜。镇长健康且存活、日终恰有三人存活且没有处决触发好人胜；处决尸体也算处决。
- 三人局不套用善恶人数相等或票数推断；保留平板手动指定胜方，并标记人工结果。说书人不计入角色座位与存活人数。
- 处决至少达到该轮结算时存活人数的一半，向上取整；最高有效票并列不处决。保存每轮门槛，之后死亡不让旧的未达标票倒算为达标。
- 死者不能提名，但可被提名、处决，不会再次死亡。幽灵票仅同意消耗，反对和未投保留。
- 每人每天一次提名、一次被提名符合标准；**禁止自提名**是本桌额外约定，继续保留。手机同时提交、每轮一次、提交后不能改票，是本产品操作方式，不模拟实体逐座举手。

依据：[规则解释](https://wiki.bloodontheclocktower.com/Rules_Explanation)、[处决与死亡不同](https://wiki.bloodontheclocktower.com/States)、[词汇表](https://wiki.bloodontheclocktower.com/Glossary)。

## 四、信息隔离与裁量边界

夜间死亡立即改变引擎状态，阻止死者普通行动；黎明前，公共屏、普通手机公开座位及行动选人列表不提前显示当夜死亡。守鸦人私下获得死亡触发操作，间谍按能力看真魔典；当场结束则正常公开复盘。

魔典包含真实角色、醉毒、死亡、红鲱鱼、保护、主人、一次性能力使用、首夜已发配对标记与恶魔伪装提示。这些不进入普通玩家或公共屏。

默认自动信息使用固定合法登记策略；AI 候选额外采样隐士/间谍登记，每次判定可不同，不是全部组合穷举。醉毒可收真假信息，但不能实际发动不存在的能力。镇长转移、传位及日间登记目前由引擎选择，DeepSeek 仍只选夜间信息候选。

## 五、验证与升级

专项测试 `tests/rules.test.js`、旧引擎回归 `tests/engine.test.js`，结合手机渲染、整局、模拟与本地联机检查操作和隔离。完整结果见 [本轮验证记录](../官方规则核对验证_20261022.md)。

存档 v2 新增恶魔伪装与信息标记的兼容默认值；读旧局不重发身份或追补隐私信息。无法撤回旧版本已经发出的同伙角色信息和错误结算，所以更新正式版本应在一局结束后，再另开新局。真实安卓、公网链路与真实 DeepSeek 仍需分别验收。
