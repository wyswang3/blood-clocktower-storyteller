本次交付

0.4.1 额外修正单独测试连接与更换密钥并发时的等待状态，测试结束可重试；新增回归，验证总数为 231。

  • 平板大厅直接提供“连接 DeepSeek”，设置内也保留入口。填写 API Key 后自动选预置模型、验证一次、保存并启用；不需要用户编辑 JSON、填写接口地址或下载模型。
  • API Key 使用密码框，确认/取消后清空；不进浏览器存储、URL、公共状态、对局存档和日志，也不回显给房主。只保存在服务端私密配置。
  • 仅房主、本机或可信本机 HTTPS 代理连接可以提交。普通玩家、说书人、明文远程局域网请求被拒绝。页面不接受模型和端点参数。
  • 新密钥验证及原子保存成功后才热加载；失败保留旧设置与连接。输入格式、无效密钥、余额不足、限流、超时与写盘失败使用中文说明。
  • 忙状态阻止重复收费测试；断线重连可恢复进度。连接测试无魔典，真实使用时只有私密裁量发送魔典。
  • GUI 保存 managedByUI:true，启动读取保存的密钥与启停；暂停也记住。新连接替换时取消旧请求并按引擎回退。
  • 暂停立即生效，即使设置无法保存也保持本次暂停并提示；启用保存失败则恢复原开关。
  • 新增 ai-settings 写盘后确认，避免把先前的公开状态误认为保存完成。
  • 更新安装、使用、维护、配置说明及 README，补充标准僧侣连续守护回归。
