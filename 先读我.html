血染钟楼 · 使用与维护说明

版本 0.4.0 · 2026-10-22 · 安卓平板 + 每人一部手机

本文件已包含四份完整手册、AI 配置与本轮验证记录，点目录即可跳转，可离线阅读。程序由平板上的 Termux 启动，游戏界面在浏览器打开。

平板主人从压缩包开始：安装、配置 AI、测试连接和正式开局。所有玩家加入房间、看身份、夜间行动、提名投票和掉线处理。Agent 与技术人员当前实现、验证证据、目标、待办和后续维护流程。规则核对22 角色、当前官方夜序、胜负、操作约定与测试依据。

DeepSeek 配置详解

首次安装环境、各用不同网络开局，以及 AI 调用需要互联网。首次可以直接开局；点“连接 DeepSeek”填密钥后，会自动验证、保存并启用，以后会记住开关。

当前已完成本地模拟与接口测试；真实 DeepSeek 账户、安卓设备和公网运营商链路仍需按指南验收。

平板主人的安装与测试指南

适用版本：0.4.0｜更新日期：2026-10-22｜设备：安卓平板。

这台平板负责运行游戏和显示公共局面。你自己也可以拿手机参加游戏；平板操作不需要你知道其他人的身份。程序通过 Termux 启动，游戏界面在浏览器打开。

一、先准备这些

  • 安卓平板，建议 Android 7 或更新版本，保留足够空间并准备充电器。
  • 本次交付的 blood-clocktower-android-ai.zip。
  • Termux，按 官方安装说明 选择来源。
  • 安装时需要互联网。聚会时若各用自己的网络，平板和每部手机都需要持续联网。
  • 使用 AI 时需要 DeepSeek API Key。先不填密钥，也能测试纯自动情报模式。

二、第一次安装

  1. 把压缩包保存到平板的“下载 / Download”文件夹。若已在文件管理器解压，可以先打开其中的 先读我.html 看说明；运行程序仍按下面步骤进行。
  2. 安装并打开 Termux。逐行复制执行：
pkg update
pkg install nodejs-lts unzip
termux-setup-storage

出现文件访问权限提示时允许。安装软件包时若询问是否继续，输入 y 并回车。

  1. 解压到 Termux 自己的目录：
unzip ~/storage/downloads/blood-clocktower-android-ai.zip -d ~/
cd ~/blood-clocktower
sh start-android.sh
  1. 看到“本机（平板）”地址和“房主 PIN”，表示服务已经启动。保持 Termux 运行，切换到浏览器，打开显示的本机地址。它类似 http://127.0.0.1:3000/host?pin=四位数字，PIN 以你屏幕上实际显示的为准。
  2. 在系统设置中，允许 Termux 后台运行，把电池策略设为“不限制”或同等选项。聚会时让平板持续供电，避免清理后台。

程序没有第三方 npm 依赖，不需要执行 npm install，也不需要安装额外的游戏 APK。

三、先做一个小测试

先不要急着开正式局，按顺序确认：

检查怎么做通过标准
平板服务浏览器打开 http://127.0.0.1:3000/health显示包含 "ok":true 的文字
公共屏打开终端给出的本机房主地址能看到大厅、人数与座位
手机入座一部手机打开加入链接，输入名字并选座平板能看到这部手机加入
后台运行切到浏览器并等待几分钟Termux 没被系统停止，手机没有持续掉线

这一步只证明基本连接。七个人是否都能顺畅使用，需要后面的全员测试。

四、让大家各用流量或 Wi-Fi

你们计划使用这一种。平板可以连谁的热点，也可以连普通 Wi-Fi；其他人各自有网即可。

  1. 回到 Termux，按 Ctrl+C 停止刚才的服务。Termux 可用底部扩展键的 CTRL 配合字母 C。
  2. 第一次额外安装：
pkg install cloudflared
  1. 启动公网房间：
cd ~/blood-clocktower
sh start-android.sh --tunnel
  1. 平板仍用“本机（平板）”地址。等待大厅出现类似 https://某个名字.trycloudflare.com/player 的加入链接，点“复制链接”或“分享链接”，只发给这桌朋友。
  2. 找一部手机关闭 Wi-Fi、只用流量打开这个链接。如果能入座，再让其他人加入。

手机不能使用 127.0.0.1，也不要分享带 pin= 的房主地址。 平板重启隧道后公网地址会改变，要重新分享。临时隧道的网络可用性需要现场确认；打不开时先尝试更换平板网络。

备用方案：让大家连同一个 Wi-Fi 或热点，用平板的局域网地址加入。关闭 AI 的局域网模式在安装完成后不需要互联网。

五、连接 DeepSeek（点按钮即可）

  1. 在平板大厅点 “连接 DeepSeek”。
  2. 粘贴你准备好的 API Key（密钥），点 “保存并连接”。只填密钥，不填网址或代码。
  3. 等待“DeepSeek 已连接并启用，设置已保存”。程序已自动选好模型，不需要下载模型，也不需要编辑文件或重启。

这会发起一次小测试，按 DeepSeek 账户规则计费，但不发送对局身份、不开始游戏。没有密钥也可以先开局。

以后启动自动读取设置；想不用 AI 就点“暂停 AI”，下次启动也会记住暂停。换密钥点“更换 DeepSeek 密钥”，新密钥失败不会覆盖原来的设置。

若提示只能在本机或 HTTPS 页面填写，请在平板启动窗口用“本机（平板）”链接打开。手机玩家不用填密钥。详细故障说明见 连接 DeepSeek。

六、聚会前的全员测试

请在正式玩的地点，至少完整走一夜：

  1. 平板和七部手机全部进入同一房间，每人固定一个座位。
  2. 开始游戏，所有人都能按住查看自己的身份，并点“我知道了”。平板只显示确认人数。
  3. 开始第一夜。被叫到的人完成选人或情报确认，其他人继续等待。检查自己能否读懂手机提示。
  4. 确认夜间能自动走到天亮；不能只依靠连续“跳过”证明游戏正常。
  5. 平板开始提名，一人提名另一人，大家投一次票。核对手机反馈和平板票数。
  6. 让一部手机切后台再回来，检查是否恢复原座位；不要清浏览器数据。
  7. 如开启 AI，观察有裁量空间的信息请求能否完成；失败时应自动发情报，不能把整桌卡住。固定答案不会调用模型。
  8. 测试局结束后，点“重开一局”准备正式游戏，避免沿用测试身份。

目前代码和模拟联机已验证；你们的安卓平板、浏览器及运营商网络尚未真机确认。上面这次全员测试是交付验收的一部分。

七、每次开局与结束

平时只需要：联网 → Termux 运行启动脚本 → 平板打开公共屏 → 分享当前加入链接 → 等人齐 → 开始游戏。启用 AI 前可以先测一次连接。

白天的“开始提名”“结束提名”、进入下一夜仍由平板操作。全桌确认不用继续时，可点“提前结束”，输入“好人”或“坏人”并再次确认；会立即亮牌。

结束后回 Termux 按 Ctrl+C，对局保存在 room.json。再次启动会恢复；“重开一局”用于重新发牌。

八、升级、备份和常见问题

升级应在一局结束后，先停止服务、保留旧目录。可在 Termux 执行 cp -a ~/blood-clocktower ~/blood-clocktower-backup-20261022；后续换未使用过的备份名。尤其保留 room.json 与 ai.local.json，不要发群里。0.4.0 可读旧存档，但不能撤回旧版已发信息；升级后另开一局、先做小测试。最新运行包也可从私密 GitHub 仓库的 Releases 下载，需有权限的账号登录。

现象先检查
手机打不开链接是否用了当前公网 /player 链接，是否误用了本机或旧隧道地址
平板能开、手机不能开隧道是否就绪；局域网模式下是否同网、有设备隔离
切到浏览器后全部掉线Termux 是否被省电或后台清理停止
无法自动识别平板 IP共同局域网时从 Wi-Fi 详情查看；公网模式等待隧道链接
提示端口被占用是否已经有一个游戏服务在运行；先回原终端停止旧服务
AI 失败但游戏继续已回退，先继续对局；休息时检查配置和网络
手机丢失座位先回原浏览器和原链接，不要立即清数据或重开

遇到问题，记录发生步骤、时间、手机和平板系统版本、错误提示即可。截图不要带身份卡、PIN 或 API Key。

玩家使用说明

适用版本：0.4.0｜更新日期：2026-10-22。

平板放在桌中央显示公开局面，每个人的手机只接收自己的身份和操作。说书人负责主持与裁量；这一版由程序处理流程，可选 DeepSeek 帮助选择夜间情报。讨论和推理仍由你们自己进行。

一、加入这桌游戏

  1. 打开平板主人分享的当前加入链接，通常以 /player 结尾。
  2. 输入名字，认领一个空座位。按你们实际围坐的顺序选座，避免邻座信息与现实位置混淆。
  3. 后续继续用同一浏览器打开同一链接。手机会记住座位，不需要账号。

使用公网房间链接时，可以各用流量或 Wi-Fi。使用局域网链接时，需要连同一个 Wi-Fi 或热点。两种链接不要混用；不确定时以平板主人刚分享的为准。

二、手机上的四个页面

页面用途
局面当前阶段、夜间操作、白天提名和投票
推理查看角色表，记录自己对其他人的身份猜测
情报回看自己收到的信息、公开提名和票型
身份按住查看自己的身份和技能

自己的怀疑标记和身份猜测不出现在别人的手机或平板公共屏上。后台说书人策略具备读取相关数据的接口，未来完整 AI 可能将其作为约定的参考；本版 DeepSeek 裁量主要读取魔典、当前情报请求和既往裁量。

三、发牌后做什么

按住身份卡查看，松手盖回去；看完点“我知道了”。如果找不到确认，回“局面”或“身份”页查看。不要把身份卡展示给旁边的人。

酒鬼看到的也只会是一个镇民身份。 游戏中不会提醒“你是酒鬼”或“你中毒了”。信息可能因醉酒、中毒或角色登记而有误，需要结合规则推理；不是看到矛盾就说明程序出错。

酒鬼没有他以为的镇民能力。酒鬼收到真信息是允许的，但并不代表他的镇民能力真的生效。

四、夜晚怎么操作

AI 由平板主人配置，你的手机不用填写密钥。僧侣按标准规则可连续两晚守护同一个人，不能守自己。

  1. 进入夜晚后，手机屏幕朝向自己，避免旁人看到。默认静音，不会公开叫某号玩家行动。
  2. 轮到你时，手机会显示操作。需要选人就按要求选择，再确认；收到信息后点“我看到了”。
  3. 没有轮到你时保持等待。无夜间能力的人可能整个夜晚都没有操作。
  4. 显示“说书人正在准备情报”时稍等；模型调用失败会回退到程序结果，不需要你重新提交。

不要用操作声音或拿起手机的时机告诉别人自己的角色。手机锁屏后返回，如提示断线，给它一点时间重连；卡住再告诉平板主人，不要自己清缓存。

第一夜按《暗流涌动》流程，小恶魔不杀人；守鸦人等角色只会在满足条件时行动。其他剧本的首夜不能据此类推，目前只实现暗流涌动。

五、白天讨论、提名和投票

讨论倒计时只是提醒，归零不会自动结束讨论。由平板主人开启提名后，手机才会出现提名入口。

本桌采用以下提名约定，“每天”指一个白天，不是一次投票：

  • 每人每个白天最多提名一次。
  • 每人每个白天最多被提名一次。
  • 不能提名自己。
  • 一次只处理一轮投票；投票结束后再提名。
  • 次数第二天重置，刷新或重连不能重置。

提名后点击“同意”或“反对”。这一版同时用手机投票，每轮只能提交一次，不能提交后改票。全部有资格的人回应、计时结束或房主手动关闭时结算。

处决须达到该轮结算时存活人数的一半，向上取整，并为当天最高有效票；并列或不足不处决。七存活至少四票，三存活至少两票。之后死亡不让旧未达标票数倒算通过。

死者可被提名、处决，但不再次死亡；死者不能发起提名。管家请自行遵守跟投规则：死主人仍须用幽灵票才可跟投；误投照计，仅私密提醒，不公开作废以验证身份。

所有存活者可公开宣称杀手，只有真实一次性能力会产生效果；可选自己/死者，也可在投票中使用。重复假宣称不恢复能力。只宣布死亡或无事发生，不公布身份。

六、死亡后仍然参与

你仍可发言、讨论、记录和帮助队友。死亡后不能提名或使用普通能力；守鸦人被夜杀后的那次能力按手机提示处理。

你有一张整局只能使用一次的幽灵票：投同意时才消耗，反对、超时或不投都不消耗。 同一轮回应后仍然不能修改或再投，保留的票可在之后的提名使用。用掉后投票按钮会消失。

死人票可以改变三人残局，所以系统不会仅因“一好人、一爪牙、一恶魔”就自动结束。

七、结束与复盘

满足胜负条件时，系统显示结局并亮出身份。全桌确认结果已无悬念时，平板主人也可手动提前宣布，记录会标明这一点。

游戏结束后可以回看全员身份、票型和死亡时间线。酒鬼到这一刻才会揭晓真实身份。当前 AI 的裁量理由保存在服务端，普通手机尚无专门查看入口；需要时请维护者协助复盘，避免把含身份和登录 token 的整个存档发到群里。

八、遇到问题

问题你可以做什么
没出现提名按钮确认处于提名阶段、自己存活、今天还没提名且存在合法目标
不能选择某人对方可能已被提名，或当前技能不允许该目标
轮不到自己可能本来没有这次夜间行动，先看技能说明
换浏览器后没有座位回原浏览器；不要反复抢别人的座位
掉线回到原链接等重连；仍不行再请平板主人检查
AI 暂时不可用程序会自动发情报，游戏可以继续

当前没有游戏内文字聊天室、语音识别或自动语音主持。“同一个房间”是指共同加入一桌；线下大家照常说话。如果分处不同地点，需要另外使用语音通话工具。

技术手册与进度管理

版本：0.4.0｜基线日期：2026-10-22｜维护对象：后续 agent 与技术人员。

本文是当前实现、证据和待办的主入口。功能状态以代码与本轮验证为准；早期《技术路线.md》《说书人设计.md》保留目标背景，不得把其中的规划当成已经实现。

1. 产品目标与当前范围

目标：几个朋友线下玩《血染钟楼》，无人需要专职退出当说书人。安卓平板同时运行服务器和公共屏，每人一部手机。朋友可各用流量或 Wi-Fi，加入同一个公网房间；也保留共同局域网方案。

最终说书人应能在合法范围内主动安排信息、观察局势、照顾新手、引导讨论、营造气氛和解释复盘。后续主模型计划使用 DeepSeek。维持可解释性和推理空间，不能靠改写已发生事实强行平衡胜负。

当前实现暗流涌动 22 角色、5–15 人、单进程单房间。0.3.0 完成当前范围的规则核对与修复，详情见 逐角色核对。0.4.0 新增平板填写密钥后自动连接、保存和热加载；0.2.0 起已有夜间信息候选选择；完整 AI 主持、账号系统、原生游戏 APK、游戏内聊天和语音尚未实现。

2. 状态定义

状态含义

4. 架构与数据流

6. DeepSeek 配置和协议

普通用户见 连接 DeepSeek，直接用大厅按钮。没有图形设置标志时环境变量优先：DEEPSEEK_API_KEY、DEEPSEEK_BASE_URL、DEEPSEEK_MODEL、AI_TIMEOUT_MS、AI_ENABLED。默认关闭，密钥有效配置后才允许从平板启用。默认模型 deepseek-flash，以本次查询官方文档为依据，不应永久硬编码模型可用性假设。

请求：POST {baseUrl}/chat/completions，Bearer 认证、非流式、非思考模式、JSON 输出，最多 512 输出 token。普通端点要求 HTTPS；仅允许本机 HTTP 作为测试替身。

模型输出：{"optionId":"option-0","reason":"私密的简短裁量依据"}。只使用通过验证的编号，实际卡片取自服务器候选；多余的模型卡片和身份字段不会被采用。无裁量空间时不调用服务商。

房主 WebSocket 消息：{t:'host', action:'setAI', enabled:true|false}；单次连通测试为 {t:'host', action:'testAI'}。均受房主 PIN 会话权限保护。测试发送空对局上下文，返回 ai-test 消息；不修改游戏。

public.ai 仅公开 configured / enabled / state。room.aiDecisions 保留最近 100 条私密记录。API Key 仅用于认证头，不进入模型消息正文；座位 token、房主 PIN 不发送给模型。魔典进入私密裁量请求，不得复用于未来公开主持。

候选由信息生成器采样去重，加入健康隐士/间谍每次互动可变化的登记；默认自动模式仍用固定合法策略，不穷举所有组合。镇长转移、传位和日间登记由引擎自动选，模型无权直接执行特殊效果。旧可信外部 st-info 协议允许自由卡片，与受约束的 DeepSeek 适配器是不同入口。

7. 必须守住的约束

  • 酒鬼真实角色仍是外来者，显示角色只能是本局未在场的镇民。模型没有改身份的权限。
  • 清醒健康能力的结果不能自由造假；醉毒可给真或假信息，真实能力效果仍按规则执行。
  • 自动结算不按善恶票数直接结束三人局。提前宣布使用已授权的房主入口。
  • 提名“每轮”在本项目指每个白天，每人一次提名、一次被提名；禁止自提是用户确认的本桌约定。
  • 幽灵票仅同意消耗，反对和未投不消耗；本轮资格分母不能随投票缩小。
  • 一条请求只执行一次；超时、跳过、模式切换、暂停、重开后迟到结果不得覆盖当前请求。
  • 身份、醉毒、魔典、AI 理由不得进入公共屏；用户数据、模型输出和玩家名称都按数据处理。
  • 禁止根据旧设计稿直接实现白天改酒鬼、任意改红鲱鱼或改写既有事实。

连接 DeepSeek：平板上填一次就好

适用版本：0.4.0。普通使用者不需要编辑文件、输入代码、选择接口地址或下载模型。

第一次连接

  1. 在安卓平板上启动游戏，用启动窗口显示的“本机（平板）”房主链接打开大厅。
  2. 点大厅里的 “连接 DeepSeek”。
  3. 粘贴 DeepSeek 的 API Key（密钥），点 “保存并连接”。只填密钥，不填代码或网址。
  4. 等待“DeepSeek 已连接并启用，设置已保存”。这样就可以开始游戏了。

还没有密钥时，可由你在 DeepSeek 官方平台 创建并复制。各玩家的手机不用配置密钥。填写时用密码框遮住内容，确认或取消后清空输入框；不要把密钥发到聊天或群里。

连接按钮会自动使用预置的 DeepSeek 模型，并发起一次小测试，按你的 DeepSeek 账户规则计费。测试不发送对局身份、不开始游戏。模型在云端运行，平板不需要下载或安装模型文件。无需反复点击，连接中会显示进度。

以后怎么用

  • 下次启动会自动读取已保存的密钥和开关，不用重新填写。
  • 点“暂停 AI”可回到自动情报模式，并记住暂停状态；点“启用 AI”恢复。
  • 换密钥时点“更换 DeepSeek 密钥”。新密钥验证与保存均成功后才替换旧连接，失败保留旧设置。
  • 不连接 AI 也可以开局。夜间调用失败会自动发出引擎情报，整桌仍能继续。

密钥只在平板本机房主页面或 HTTPS 房主页面填写。若从普通局域网 HTTP 地址打开而提示不能填写，请回到平板启动窗口，用“本机（平板）”链接打开；原有加入链接仍可给玩家用。

当前 AI 的范围

目前接通夜间私密情报裁量：引擎生成合法信息候选，DeepSeek 选择编号。它不能改身份、死亡、票数或让酒鬼能力真实生效。公开主持、规则问答、语音和完整特殊能力裁量仍在规划中。

最长 12 秒请求，15 秒引擎兜底；失败不反复收费重试。暂停、跳过、重开或替换连接时，旧请求取消或迟到结果被丢弃。

维护者附录

密钥不回显、不进浏览器存储、对局存档、公共视图、日志、Git 或压缩包。临时配置同样忽略。服务端以 0600 创建私密临时文件并原子替换；实际文件权限仍受设备系统影响。

三、胜负与投票

  • 真恶魔死亡后先处理合法接管/传位；仍无存活真恶魔则好人立即胜。仅剩两人且恶魔存活则邪恶立即胜，不继续发夜间信息。
  • 圣徒健康且因处决死亡触发邪恶胜。镇长健康且存活、日终恰有三人存活且没有处决触发好人胜；处决尸体也算处决。
  • 三人局不套用善恶人数相等或票数推断；保留平板手动指定胜方，并标记人工结果。说书人不计入角色座位与存活人数。
  • 处决至少达到该轮结算时存活人数的一半，向上取整；最高有效票并列不处决。保存每轮门槛，之后死亡不让旧的未达标票倒算为达标。
  • 死者不能提名，但可被提名、处决，不会再次死亡。幽灵票仅同意消耗，反对和未投保留。
  • 每人每天一次提名、一次被提名符合标准；禁止自提名是本桌额外约定，继续保留。手机同时提交、每轮一次、提交后不能改票，是本产品操作方式，不模拟实体逐座举手。

依据：规则解释、处决与死亡不同、词汇表。

四、信息隔离与裁量边界

夜间死亡立即改变引擎状态，阻止死者普通行动；黎明前，公共屏、普通手机公开座位及行动选人列表不提前显示当夜死亡。守鸦人私下获得死亡触发操作，间谍按能力看真魔典；当场结束则正常公开复盘。

魔典包含真实角色、醉毒、死亡、红鲱鱼、保护、主人、一次性能力使用、首夜已发配对标记与恶魔伪装提示。这些不进入普通玩家或公共屏。

默认自动信息使用固定合法登记策略；AI 候选额外采样隐士/间谍登记，每次判定可不同，不是全部组合穷举。醉毒可收真假信息，但不能实际发动不存在的能力。镇长转移、传位及日间登记目前由引擎选择，DeepSeek 仍只选夜间信息候选。
