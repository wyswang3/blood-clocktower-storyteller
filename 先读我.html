平板主人的安装与测试指南

适用版本：0.5.0｜更新日期：2026-10-23｜设备：安卓 8.0 及以上平板。

平板运行房间服务并显示公共局面，每人用自己的手机看身份和投票。平板主人也能参加游戏，日常操作不会显示其他人的身份。

一、下载和安装

  1. 下载本次交付的 blood-clocktower-v0.5.0.apk，保存到平板。也可登录有权限的 GitHub 账号，在 最新版本 的附件中下载。
  2. 在“文件管理 / 下载”中点这个 APK。若系统询问，允许这次使用的文件管理器“安装未知应用”，然后点“安装”。不需要开启开发者模式或 USB 调试。
  3. 安装后点 “血染说书人” 图标。首次准备可能稍慢，等到大厅出现即可。若询问是否允许通知，建议允许，方便确认房间仍在运行。

不用安装 Termux，不用解压游戏源码，不用输入命令，也不用单独安装联网工具。 应用已包含游戏服务和公网连接组件，模型仍在 DeepSeek 云端。

需要安卓 8.0 及以上；安装包包含常见的 64 位和 32 位 ARM 平板版本，也包含用于电脑安卓模拟器的版本。你们的具体平板仍需按下面步骤实测。

安装包约 91 MB。常见 64 位 ARM 平板安装后的基础占用预计约 180–200 MB，安装时建议至少留出 500 MB 可用空间，供下载、解包和系统临时文件使用；实际以系统应用详情为准。DeepSeek 模型在云端，不会往平板下载几个 GB 的模型。手机只打开网页，不需要下载 APK 或源码 ZIP。

二、第一次开局：三步

  1. 连接 AI（可跳过）：大厅点“连接 DeepSeek”，粘贴 API Key，点“保存并连接”。等待提示已连接、已保存。不要填代码、网址或模型名。
  2. 邀请朋友：顶部出现“公网房间已连接”后，点“分享加入链接”，把链接发给这桌朋友。大家用手机浏览器打开、输入名字并选座位。
  3. 开始游戏：所有人到齐后，在平板点“开始游戏”，各自在手机确认身份，再由平板开始第一夜。

平板上网可以用普通 Wi-Fi，也可以连某个人的热点。公网连接成功后，其他人可以各用流量或不同 Wi-Fi。玩家手机不用安装 APK，也不用填写密钥。

AI 连接测试会产生一次很小的接口调用，按 DeepSeek 账户规则计费。不连接 AI 也能完整开局；夜间 AI 失败会自动回退。首次配好后，下次打开自动读取；暂停 AI 也会被记住。详见 DeepSeek 配置。

三、公网不通时怎么处理

  1. 先确认平板能正常打开普通网页；热点供网的手机也需要有流量。
  2. 点顶部“连接设置 → 重新连接公网”。连接变化后要分享新链接，朋友重新打开。应用也会自动重试。请在发牌前确认大家能加入。
  3. 仍然连不上时，改用“连接设置 → 大家连同一 Wi-Fi / 手机热点”，让所有手机和平板连接同一个网络，再分享链接。

公网房间使用临时连接服务，不需要账号或域名，但可达性取决于现场网络；仅填写 DeepSeek 密钥不能解决公网不可达。旧链接失效时应用会撤回。

对局中尽量保持平板网络和服务不变。 同一链接下的普通断线可以恢复座位；如果临时公网地址、局域网 IP 或端口改变，手机会将它视为新网站，本版还不能自动找回旧地址下的座位。平板存档仍保留，但可能需要另开一局，不能把“重新分享链接”理解为无损恢复所有手机。最好在聚会前完成不同网络测试。

同一 Wi-Fi / 热点模式下，关闭 AI 后可以不联网玩。游戏主要传文字，七台手机的游戏流量很小；若连不上，还应检查路由器设备隔离、热点人数上限或省电策略。

五、平时需要记住的操作

  • 平板保持供电和联网。系统电池设置若有“不限制后台运行”，可对“血染说书人”开启；不要在游戏中清理后台。
  • 返回桌面会继续运行房间；通知栏点一下可回来。真正结束时点顶部“关闭房间 → 保存并关闭”。下次打开可恢复。
  • 顶部“连接设置”可切换公网/同网模式、重连或重启服务；不会重新发牌。网络恢复后链接可能改变，要重新分享。
  • 白天的“开始提名”“结束提名”、进入下一夜仍需要平板操作。
  • 全桌决定提前结束时，在游戏设置里选择“提前结束”、输入获胜方并再次确认；会亮牌。自动判定仍使用标准规则。

玩家使用说明

适用版本：0.5.0｜更新日期：2026-10-23。

平板放在桌中央显示公开局面，每个人的手机只接收自己的身份和操作。说书人负责主持与裁量；这一版由程序处理流程，可选 DeepSeek 帮助选择夜间情报。讨论和推理仍由你们自己进行。

一、加入这桌游戏

  1. 打开平板主人分享的当前加入链接，通常以 /player 结尾。
  2. 输入名字，认领一个空座位。按你们实际围坐的顺序选座，避免邻座信息与现实位置混淆。
  3. 后续继续用同一浏览器打开同一链接。手机会记住座位，不需要账号。

使用公网房间链接时，可以各用流量或 Wi-Fi。使用局域网链接时，需要连同一个 Wi-Fi 或热点。两种链接不要混用；不确定时以平板主人刚分享的为准。

座位由浏览器按网址保存。同一网址下刷新或短暂断线可以恢复；如果公网域名、IP 或端口变了，本版还不能自动转移原座位。不要在对局中主动切换房间网址或清除浏览器数据。

二、手机上的四个页面

页面用途
局面当前阶段、夜间操作、白天提名和投票
推理查看角色表，记录自己对其他人的身份猜测
情报回看自己收到的信息、公开提名和票型
身份按住查看自己的身份和技能

自己的怀疑标记和身份猜测不出现在别人的手机或平板公共屏上。后台说书人策略具备读取相关数据的接口，未来完整 AI 可能将其作为约定的参考；本版 DeepSeek 裁量主要读取魔典、当前情报请求和既往裁量。

三、发牌后做什么

按住身份卡查看，松手盖回去；看完点“我知道了”。如果找不到确认，回“局面”或“身份”页查看。不要把身份卡展示给旁边的人。

酒鬼看到的也只会是一个镇民身份。 游戏中不会提醒“你是酒鬼”或“你中毒了”。信息可能因醉酒、中毒或角色登记而有误，需要结合规则推理；不是看到矛盾就说明程序出错。

酒鬼没有他以为的镇民能力。酒鬼收到真信息是允许的，但并不代表他的镇民能力真的生效。

四、夜晚怎么操作

AI 由平板主人配置，你的手机不用填写密钥。僧侣按标准规则可连续两晚守护同一个人，不能守自己。

  1. 进入夜晚后，手机屏幕朝向自己，避免旁人看到。默认静音，不会公开叫某号玩家行动。
  2. 轮到你时，手机会显示操作。需要选人就按要求选择，再确认；收到信息后点“我看到了”。
  3. 没有轮到你时保持等待。无夜间能力的人可能整个夜晚都没有操作。
  4. 显示“说书人正在准备情报”时稍等；模型调用失败会回退到程序结果，不需要你重新提交。

不要用操作声音或拿起手机的时机告诉别人自己的角色。手机锁屏后返回，如提示断线，给它一点时间重连；卡住再告诉平板主人，不要自己清缓存。

第一夜按《暗流涌动》流程，小恶魔不杀人；守鸦人等角色只会在满足条件时行动。其他剧本的首夜不能据此类推，目前只实现暗流涌动。

五、白天讨论、提名和投票

讨论倒计时只是提醒，归零不会自动结束讨论。由平板主人开启提名后，手机才会出现提名入口。

本桌采用以下提名约定，“每天”指一个白天，不是一次投票：

  • 每人每个白天最多提名一次。
  • 每人每个白天最多被提名一次。
  • 不能提名自己。
  • 一次只处理一轮投票；投票结束后再提名。
  • 次数第二天重置，刷新或重连不能重置。

提名后点击“同意”或“反对”。这一版同时用手机投票，每轮只能提交一次，不能提交后改票。全部有资格的人回应、计时结束或房主手动关闭时结算。

处决须达到该轮结算时存活人数的一半，向上取整，并为当天最高有效票；并列或不足不处决。七存活至少四票，三存活至少两票。之后死亡不让旧未达标票数倒算通过。

死者可被提名、处决，但不再次死亡；死者不能发起提名。管家请自行遵守跟投规则：死主人仍须用幽灵票才可跟投；误投照计，仅私密提醒，不公开作废以验证身份。

所有存活者可公开宣称杀手，只有真实一次性能力会产生效果；可选自己/死者，也可在投票中使用。重复假宣称不恢复能力。只宣布死亡或无事发生，不公布身份。

六、死亡后仍然参与

你仍可发言、讨论、记录和帮助队友。死亡后不能提名或使用普通能力；守鸦人被夜杀后的那次能力按手机提示处理。

你有一张整局只能使用一次的幽灵票：投同意时才消耗，反对、超时或不投都不消耗。 同一轮回应后仍然不能修改或再投，保留的票可在之后的提名使用。用掉后投票按钮会消失。

死人票可以改变三人残局，所以系统不会仅因“一好人、一爪牙、一恶魔”就自动结束。

七、结束与复盘

满足胜负条件时，系统显示结局并亮出身份。全桌确认结果已无悬念时，平板主人也可手动提前宣布，记录会标明这一点。

游戏结束后可以回看全员身份、票型和死亡时间线。酒鬼到这一刻才会揭晓真实身份。当前 AI 的裁量理由保存在服务端，普通手机尚无专门查看入口；需要时请维护者协助复盘，避免把含身份和登录 token 的整个存档发到群里。

版本：0.5.0｜更新日期：2026-10-23｜维护对象：后续 agent 与技术人员。

本文是当前实现、证据和待办的主入口。功能状态以代码与本轮验证为准；早期《技术路线.md》《说书人设计.md》保留目标背景，不得把其中的规划当成已经实现。

1. 产品目标与当前范围

目标：几个朋友线下玩《血染钟楼》，无人需要专职退出当说书人。安卓平板同时运行服务器和公共屏，每人一部手机。朋友可各用流量或 Wi-Fi，加入同一个公网房间；也保留共同局域网方案。

最终说书人应能在合法范围内主动安排信息、观察局势、照顾新手、引导讨论、营造气氛和解释复盘。后续主模型计划使用 DeepSeek。维持可解释性和推理空间，不能靠改写已发生事实强行平衡胜负。

当前实现暗流涌动 22 角色、5–15 人、单进程单房间。0.3.0 完成当前范围的规则核对与修复，详情见 逐角色核对。0.4.1 新增平板填写密钥后自动连接、保存和热加载；0.2.0 起已有夜间信息候选选择；0.5.0 新增原生安卓 APK、内置 Node/cloudflared、独立后台服务、图形联网与重试；完整 AI 主持、账号系统、游戏内聊天和语音尚未实现。

6. DeepSeek 配置和协议

普通用户见 连接 DeepSeek，直接用大厅按钮。没有图形设置标志时环境变量优先：DEEPSEEK_API_KEY、DEEPSEEK_BASE_URL、DEEPSEEK_MODEL、AI_TIMEOUT_MS、AI_ENABLED。默认关闭，密钥有效配置后才允许从平板启用。默认模型 deepseek-flash，以本次查询官方文档为依据，不应永久硬编码模型可用性假设。

请求：POST {baseUrl}/chat/completions，Bearer 认证、非流式、非思考模式、JSON 输出，最多 512 输出 token。普通端点要求 HTTPS；仅允许本机 HTTP 作为测试替身。

模型输出：{"optionId":"option-0","reason":"私密的简短裁量依据"}。只使用通过验证的编号，实际卡片取自服务器候选；多余的模型卡片和身份字段不会被采用。无裁量空间时不调用服务商。

房主 WebSocket 消息：{t:'host', action:'setAI', enabled:true|false}；单次连通测试为 {t:'host', action:'testAI'}。均受房主 PIN 会话权限保护。测试发送空对局上下文，返回 ai-test 消息；不修改游戏。

public.ai 仅公开 configured / enabled / state。room.aiDecisions 保留最近 100 条私密记录。API Key 仅用于认证头，不进入模型消息正文；座位 token、房主 PIN 不发送给模型。魔典进入私密裁量请求，不得复用于未来公开主持。

候选由信息生成器采样去重，加入健康隐士/间谍每次互动可变化的登记；默认自动模式仍用固定合法策略，不穷举所有组合。镇长转移、传位和日间登记由引擎自动选，模型无权直接执行特殊效果。旧可信外部 st-info 协议允许自由卡片，与受约束的 DeepSeek 适配器是不同入口。

7. 必须守住的约束

  • 酒鬼真实角色仍是外来者，显示角色只能是本局未在场的镇民。模型没有改身份的权限。
  • 清醒健康能力的结果不能自由造假；醉毒可给真或假信息，真实能力效果仍按规则执行。
  • 自动结算不按善恶票数直接结束三人局。提前宣布使用已授权的房主入口。
  • 提名“每轮”在本项目指每个白天，每人一次提名、一次被提名；禁止自提是用户确认的本桌约定。
  • 幽灵票仅同意消耗，反对和未投不消耗；本轮资格分母不能随投票缩小。
  • 一条请求只执行一次；超时、跳过、模式切换、暂停、重开后迟到结果不得覆盖当前请求。
  • 身份、醉毒、魔典、AI 理由不得进入公共屏；用户数据、模型输出和玩家名称都按数据处理。
  • 禁止根据旧设计稿直接实现白天改酒鬼、任意改红鲱鱼或改写既有事实。

14. 0.5.0 原生安卓封装

架构和生命周期

MainActivity 是原生启动器和受限 WebView；RoomService 在独立的 :room 进程启动内置 Node.js，游戏引擎与手机协议共用原有实现。应用打开后直接进入已认证的本机房主页面，不需要终端或手输 PIN。平板仍是唯一房间服务器。

Node.js Mobile 不支持同一进程中停止后再启动 V8，因此停止时先通过私密接口落盘、结束隧道，再结束独立服务进程。重启按钮重建该进程，主界面重新绑定。前台服务有持续通知和 CPU 唤醒锁，平板显示时保持屏幕点亮；后台存活仍受厂家省电策略影响，必须真机验收。

数据与权限

  • 应用 ID 固定为 com.wyswang.clocktower，最低 Android 8.0，目标 API 35，包含 arm64-v8a、armeabi-v7a、x86_64。升级需递增 versionCode 并保留签名。
  • 游戏资源复制到应用私有的 files/game-{version}，配置与存档独立放在 files/ai.local.json、files/room.json。覆盖安装保留；卸载或清除数据删除。关闭自动系统备份，不从共享下载目录执行代码。
  • WebView 只在内部打开本机端口；禁用 file/content 访问，不安装 JavaScript 原生桥。外部网页交给浏览器。DeepSeek 密钥仍只经过原房主配置流程。
  • Java 与服务之间使用非导出 Binder；每次服务启动生成 32 字节随机管理令牌。/__native/* 同时要求本机源地址、准确的 127.0.0.1 Host 和管理头。令牌不进网页、游戏存档、控制台和加入链接。公开接口不返回房主 PIN。
  • 管理接口：GET /__native/status；POST 的 /retry、/mode/internet、/mode/lan、/network/{IPv4或none}、/stop 均位于 /__native 下。状态仅 Java 层使用；停止先保存再响应。

联网

APK 内置从 Cloudflare 官方 2026.10.3 源码用 Android NDK / Go 编译的 cloudflared。使用 HTTP/2 临时隧道，默认尝试公网连接，不需要 Cloudflare 账号或域名。URL 与注册成功同时出现才公布链接；失败/退出清除链接，10 秒后重试，切网和手动重试取消旧进程。切到同网模式立即停止隧道。

原生系统 API 提供局域网 IP，解决部分安卓禁止 Node 枚举网卡的问题。公网和同网链接不能混淆；同网模式不能承诺所有手机热点允许设备互访。现场公网不可达时按主人指南切换，不把密钥错误当成隧道故障。

构建与签名

私密仓库 .github/workflows/android.yml 使用 JDK 21、Gradle 8.9、AGP 8.7.3、SDK 35、NDK 27.2、CMake 3.22.1 构建和 lint，并安排 Android 模拟器验收。Node.js Mobile 18.20.4 官方压缩包固定 SHA-256；cloudflared 使用官方固定标签、go.sum 校验依赖。源码包不含已下载运行库和编译缓存。

构建物下载后，维护者运行 tools/sign-android.ps1 在本机签名并核验。私钥与 DPAPI 加密密码位于忽略的 artifacts/android-signing/，不上传仓库、构建服务或发布附件。密码解密依赖当前 Windows 用户；迁移维护机器前应由当前用户安全导出并备份签名材料。签名丢失会影响覆盖更新，不能随意生成新签名替换。

本版沿用 Node.js Mobile 官方现成运行库；上游版本较旧。必须持续关注运行库更新与 16 KB 页设备兼容性，不能把三种 ABI 已打包等同于所有安卓机型通过。用户具体平板、真实 DeepSeek、移动运营商及长时间后台测试仍列为待验。

旧 Termux 数据不会自动导入。确需迁移时，先停止两边的服务，通过受控本地方式把原 room.json 与 ai.local.json 放入应用私有目录；当前没有面向普通用户的导入按钮，不应让用户在群里传存档或密钥。建议结束旧局后用 APK 另开新局并重新填写密钥。

存储空间与维护清理

本轮清理前工作区约 1 GB，其中构建下载、解包和测试产物约 859 MiB，用户原始图片约 152 MiB；实际 public/ 资源约 5.29 MiB。原图、源码、历史备份和签名应保留，普通用户不需要复制整个开发工作区。

连接 DeepSeek：平板上填一次就好

适用版本：0.5.0。普通使用者不需要编辑文件、输入代码、选择接口地址或下载模型。

第一次连接

  1. 在安卓平板上点“血染说书人”图标，等待大厅出现。
  2. 点大厅里的 “连接 DeepSeek”。
  3. 粘贴 DeepSeek 的 API Key（密钥），点 “保存并连接”。只填密钥，不填代码或网址。
  4. 等待“DeepSeek 已连接并启用，设置已保存”。这样就可以开始游戏了。

还没有密钥时，可由你在 DeepSeek 官方平台 创建并复制。各玩家的手机不用配置密钥。填写时用密码框遮住内容，确认或取消后清空输入框；不要把密钥发到聊天或群里。

连接按钮会自动使用预置的 DeepSeek 模型，并发起一次小测试，按你的 DeepSeek 账户规则计费。测试不发送对局身份、不开始游戏。模型在云端运行，平板不需要下载或安装模型文件。无需反复点击，连接中会显示进度。

以后怎么用

  • 下次启动会自动读取已保存的密钥和开关，不用重新填写。
  • 点“暂停 AI”可回到自动情报模式，并记住暂停状态；点“启用 AI”恢复。
  • 换密钥时点“更换 DeepSeek 密钥”。新密钥验证与保存均成功后才替换旧连接，失败保留旧设置。
  • 不连接 AI 也可以开局。夜间调用失败会自动发出引擎情报，整桌仍能继续。

密钥只在平板本机房主页面或 HTTPS 房主页面填写。APK 中直接在应用大厅操作；若使用备用命令行版，则用启动窗口显示的“本机（平板）”链接打开。手机加入链接只给玩家使用。
